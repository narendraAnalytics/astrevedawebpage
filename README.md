# AstraVeda

AstraVeda is an AI-powered Vedic astrology platform. This repository holds
the marketing website today, with a separate backend to follow as the
project grows.

## Repo layout

- `frontend/` — the Next.js marketing website (see `frontend/README.md` and
  `frontend/CLAUDE.md` for details specific to it).
- `backend/` — reserved for the platform's backend services (not yet
  created).
- `summary.txt` — full product summary (features, pricing, AI models, tech
  stack) for the mobile app that this website markets.
- `imagesurl.txt` — canonical brand asset URLs (logo, hero videos), hosted
  on Cloudinary.
- `CLAUDE.md` — project-wide conventions and design language for anyone
  (human or AI assistant) working in this repo.

## Getting started (frontend)

```bash
cd frontend
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).
